Highlight HTML with the scopes of Shiki's `html` grammar, with the CSS of `<style>` elements and the JavaScript of `<script>` elements and event handlers lexed by the CSS and JavaScript lexers.
Markdown fences named `html`, `htm`, `shtml`, `xhtml`, `inc`, `tmpl` or `tpl` are now highlighted as HTML; they were plain text before.
