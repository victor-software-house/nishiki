Highlight PHP with a lexer of its own, on by default and in `all`.
The `lang-php` feature leaves the opt-in `textmate` tier.
It turns on CSS, HTML, JavaScript, JSON, SQL and XML, which PHP's strings and heredocs embed.
Markdown's `php` fences are now highlighted as HTML and PHP in a default build, where they were HTML alone before.
