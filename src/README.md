# src

The `nishiki` crate.
The public API and its docs are on [docs.rs](https://docs.rs/nishiki); this page maps the source.

## Public API

- [`lib.rs`](lib.rs): the crate docs and the public re-exports.
- [`highlighter.rs`](highlighter.rs): `Highlighter`, which lexes one language one line at a time.
- [`language.rs`](language.rs): `Language`, and the one table every per-language list is built from.
- [`limits.rs`](limits.rs): `Limits`, the bounds on one line's work and memory, and `LineReport`.
- [`theme.rs`](theme.rs): `Theme`, which reads TextMate themes in Shiki's format and styles each scope.
- [`unstable.rs`](unstable.rs): `nishiki::unstable`, the rule engine's API under `--cfg nishiki_unstable`, exempt from semver.

## Shared by the lexers

- [`arena.rs`](arena.rs): interned scope stacks and lexer states.
- [`scope.rs`](scope.rs) and [`tag.rs`](tag.rs): scope names and frame tags, numbered in one space across languages.
- [`scratch.rs`](scratch.rs): buffers a highlighter keeps from line to line.
- [`emit.rs`](emit.rs): token and frame bookkeeping for the hand-written state machines.
- [`utf8.rs`](utf8.rs), [`space.rs`](space.rs), [`classes.rs`](classes.rs) and [`case_fold.rs`](case_fold.rs): characters as Oniguruma reads them, that is UTF-8, `\s`, the classes and `(?i)` folds.
- [`fnv.rs`](fnv.rs): a fixed-hash map for tables built from the crate's own words.
- [`bytes.rs`](bytes.rs): byte comparisons as loops, for word tables, whose cost does not follow where the bytes lie.
- [`html_words.rs`](html_words.rs): the event handler and character entity names of the `html` grammar, for every grammar that spells them the same way.
- [`test_support.rs`](test_support.rs): helpers the unit tests share.

## Engines

- [`rules/`](rules): the rule engine that languages written from a TextMate grammar share.
  Their `grammar.rs` is generated by `oracle/<language>-grammar.ts`; their matchers are hand-written.
- [`textmate/`](textmate): nishiki's own TextMate engine.
  It runs a grammar that a caller brings as JSON, under the opt-in `textmate` feature.
  It also checks the hand-written lexers.

## Languages

Each language is a module, `<language>.rs` beside `<language>/`.
Two kinds exist:

1. A hand-written state machine, such as `rust/`, `markdown/` or `typescript/`.
2. Hand-written matchers on the rule engine, such as `python/` or `cpp/`, with a generated `grammar.rs`.

A generated file marks itself as generated in its first line.
